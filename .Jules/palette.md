## 2024-05-24 - Accessibility for Icon-Only Buttons in React Native
**Learning:** Icon-only interactive elements in React Native (like `TouchableOpacity`) are not announced properly by screen readers without explicit accessibility properties. The `accessibilityLabel` must be provided, and `accessibilityRole="button"` clearly communicates the element's purpose. Furthermore, when buttons act as toggles (e.g., Favorite, Bookmark, Reblog), adding `accessibilityState={{ checked: boolean }}` is vital for screen readers to convey the current state of the toggle to the user.
**Action:** Always verify that icon-only buttons include `accessibilityLabel` and `accessibilityRole`. For buttons that toggle state, ensure `accessibilityState` is accurately tied to the component's state variables.
